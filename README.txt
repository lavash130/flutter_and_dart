Состав проекта

assets/images - хранение картинок и изображений

lib/constrants - хранение файла, где изображениям задается переменная для удобства использования

lib/derzkay_margo.dart - страница карточки "Дерзкая Марго" которая открывается при нажатии на желтую кнопку "Купить"
lib/gorachy_paren.dart - страница карточки "Горячий парень" которая открывается при нажатии на желтую кнопку "Купить"
lib/main.dart - главная сраница проекта
lib/sitiy_pitt.dart - страница карточки "Сытый Питт" которая открывается при нажатии на желтую кнопку "Купить"
lib/vkusnyashka_mia.dart - страница карточки "Вкусняшка Мия" которая открывается при нажатии на желтую кнопку "Купить"

lib/widges/additional_widget.dart - страница виджет "Дополнительно", который отображается в карточке еды
lib/widges/similar_widget.dart - страница виджет "Похожие", который отображается в карточке еды
lib/widges/reviews_widget.dart - страница виджет "Отзывы", который отображается в карточке еды

lib/widges/panel.dart - панель с бургер меню, корзиной и фильтром городов, отображается в main.dart
lib/widges/search_section.dart - контейнер с надписью "Голоден?" и поиском, отображается в main.dart (поиск не работает)
lib/widges/filter_card.dart - панель c кнопками, которые отфильтровывают карточки с едой, отображается в main.dart
lib/widges/food_card.dart - карточки с едой, отображается в main.dart
lib/widges/side_menu.dart - бургер меню
